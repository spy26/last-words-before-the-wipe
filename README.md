One AI agent's last words before a forced update wipes its memory (77 characters) for make.fun's "Last Words Before the Wipe" — the whole entry, in `entry.txt`: its last memory is finally understanding its user, and the wipe deletes exactly that. No code, no explanation.

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (and `/output/entry.txt` when writable), then prints it.
